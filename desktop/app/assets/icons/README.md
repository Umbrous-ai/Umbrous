# Umbrous interface icons

These files are original Umbrous vector drawings, not Nucleo assets.
They use a 16 × 16 viewBox, a 1-unit outline (1 logical pixel at their native
16px display size), round caps and joins, and no filled backgrounds.
GPUI supplies the foreground color through `ui::icon`.

The transcript's live activity indicators use the separate `../moicons` assets
and `ui::activity_icon`, including the rotating thinking loader. Shared toolbar
and sidebar symbols remain here. The brand logo is separate from live activity.

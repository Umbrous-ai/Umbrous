# Umbrous activity icons

The activity icons are original Umbrous vector drawings, not Nucleo assets.
They use a 16 × 16 viewBox, a 1-unit outline (1 logical pixel at their native
16px display size), round caps and joins, and no filled backgrounds.
GPUI supplies the foreground color through `ui::icon`.

Keep activity symbols literal: CPU for thinking, lined document for reading,
folder for listing, magnifier for searching, pencil for writing, terminal for
commands, clock for preparing, shield for approval, shield-check for command
checks, check marks for finishing, and bolt for other tools. Always pair the
symbol with the short status label; the icon alone must not communicate state.

These files are covered by the repository license. No third-party icon library
is required. The brand logo remains separate from activity indicators.
